=========================
Visual Editor for editors
=========================

Use this chapter to learn the Visual Editor as an editor. The first page is a
running tutorial. The remaining pages are references that you can return to
while working.

The screenshots and examples assume:

*   TYPO3 14
*   the current Visual Editor version
*   the Camino site package and its default content
*   a desktop browser
*   the light TYPO3 backend theme
*   an editor account with broad permissions
*   the Live workspace at the beginning of the tutorial

A project can expose different fields, content areas, content types, languages,
and permissions. Therefore, the exact editing targets on your site can differ
from the examples in this manual.
